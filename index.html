    Compare return models and baselines on the same historical observations.

    Run a backtest to see measured results. Models retrain at every step; larger runs can take several minutes.

    How to read these results

    Next-day models share an evaluation window. Five-session accuracy uses a different target horizon and is shown separately. Lower return MAE is better; higher directional accuracy is better.

    The zero-return baseline is used for return error. Always-up is used for directional accuracy. These are two different baselines. The direction classifier's output is a class, so its return MAE is not shown.

    Portfolio returns assume closing-price execution without fees, slippage, or execution delays. They are idealized and are not presented as investable returns here. Raw metrics remain available in the export.

    These backtests evaluate the price ensemble and its original classifier, not the experimental news direction head shown above.
